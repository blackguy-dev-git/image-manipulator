# 🖼️ Image Manipulator

A Python-based image processing project built with **NumPy** and **Pillow (PIL)**. This project manipulates image pixel data to apply basic image transformations and effects.

I'm building this project to improve my Python skills and understand how images can be processed using numerical operations.

## ✨ Features

- **Grayscale Conversion** — Converts a color image into grayscale using weighted RGB values.
- **Brightness Adjustment** — Increases image brightness by modifying pixel values.
- **Color Inversion** — Inverts RGB values to create a negative effect.
- **Horizontal Flip** — Flips an image horizontally using NumPy array operations.

## 🛠️ Technologies Used

- Python
- NumPy
- Pillow (PIL)

## 📦 Installation

**1. Clone the repository**

```bash
git clone https://github.com/blackguy-dev-git/image-manipulator.git
```

**2. Navigate to the project directory**

```bash
cd image-manipulator
```

**3. Install the required libraries**

```bash
pip install numpy Pillow
```

## 🚀 Usage

1. Place your image in the appropriate location expected by the program.
2. Run the Python script:

   ```bash
   python main.py
   ```

3. Select an available image manipulation operation.
4. View the processed image.

*Note: Update these instructions if the image path or program workflow changes.*
